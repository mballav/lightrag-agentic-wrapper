AGENTIC RAG EVALUATION SET
50 complex, multi-hop questions based on the five uploaded Acadia Statements of Work (SOWs)

Purpose
Use these questions to test a LightRAG-backed agentic wrapper's retrieval, cross-document routing, multi-hop reasoning, arithmetic, scope-boundary detection, uncertainty handling, and source-grounded responses.

Documents represented
1. Fana Jewelry — 2023 SOW
2. Hexagon / Intergraph Corporation — SEO Post-Launch Remediation SOW
3. Ethos Pet Brands — Paid Media and Analytics SOW
4. Forward Storage — SEO SOW
5. Hoffman Media — Analytics / Segmentation and LTV SOW

Evaluation guidance
- Answer from the source documents, not general assumptions.
- Keep client-specific terms separate; do not transfer pricing or notice periods between clients.
- Show arithmetic and state assumptions where a calculation depends on interpretation.
- Distinguish contractual commitments, objectives, optional services, and recommendations.
- If a detail is absent, say so and name the additional evidence needed.
- Prefer precise citations to document/page/section wherever your wrapper supports them.
- These are questions only; no answer key is included, so the file can be used as a test set.
